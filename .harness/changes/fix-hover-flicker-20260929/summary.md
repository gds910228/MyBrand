# 变更总结：悬停自激振荡修复

- **变更目录**：`.harness/changes/fix-hover-flicker-20260929/`
- **类型**：fix
- **状态**：✅ 已交付
- **触发**：用户报告「启动项目进入站点，适配有问题，鼠标指向每一处，都在猛地闪跳」

---

## 一、问题与结论

| 项 | 内容 |
|---|---|
| **现象** | 鼠标停在卡片/标签**下边缘**时，元素以约 5–8Hz 高频上下跳，画面 5–19% 像素持续剧烈变化 |
| **根因** | **悬停时让元素自身位移**（`whileHover={{ y: -N }}` / `transform: translateY(-N)`），而该元素**同时是悬停命中区** → 位移使指针脱离 → 复位 → 再位移 → 自激振荡 |
| **「适配有问题」** | 经多断点（320–1280px × 11 页面）横向溢出检查，**响应式适配未复现问题**；用户描述的「闪跳」即上述自激振荡 |
| **是否本团队引入** | **否**。涉及文件与用户提供的原始 zip **逐字节相同**（证据见 `request_analysis/spec.md` §3.2） |
| **修复** | 静止外层承担命中判定，位移交给内层；全局 `.neon-hover` 移除位移保留辉光 |
| **效果** | 三处振荡点 **2/4 → 0/4**；视觉位移效果**完整保留**（截图比对） |

## 五、决策记录

| ID | 待决议项 | 采纳 | 依据 |
|---|---|---|---|
| F-01 | 如何消除振荡 | 静止外层 + 内层位移 | 完整保留设计位移量，且从机制上根除振荡；去掉位移会丢失设计意图 |
| F-02 | `.neon-hover` 是否逐点改造 | 仅去掉位移、保留辉光 | 全局工具类涉及 10+ 调用点，改造风险与收益不成比例；该类以发光为主要反馈 |
| F-03 | 是否顺带修 `hover:translate-x-*` | 暂不改 | 实测未复现；遵循「不顺手改需求外代码」 |
| F-04 | 是否并入搜索变更目录 | 单开变更目录 | Rules 要求需求外修改单开变更 |
