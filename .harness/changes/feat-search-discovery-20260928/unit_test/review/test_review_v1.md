## 3. 无阻塞项

评审人未发现 P0/P1。特别确认了作者在 `test_report.md` §3 中宣称的「避免摆设断言」
在代码中**确实成立**：

- 时效加权用例通过「两篇文本相同、日期不同」的构造，使顺序**只能**由加权决定
  （移除 `applyRecencyWeight` 后该用例会失败）——不是存在性断言。
- 基准集每条查询同时断言 `expectAnyOf` 与 `expectNoneOf`，12 条反向用例全部有断言，
  使「靠放宽匹配换召回」无法蒙混过关。
- `safeJson` 断言「解析后与原文全等」而非仅「不抛错」。
- `searchEventStore` 断言事件字段集合，显式排除 `ip`/`userAgent`/`cookie` 等键。
